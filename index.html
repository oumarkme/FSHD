1. Biological Background

D4Z4 and FSHD

  • D4Z4 macrosatellite array on chromosome 4q35: tandem 3.3 kb repeat units
  • Healthy individuals: 11–100+ RU per allele
  • FSHD1: contraction to 1–10 RU on a permissive haplotype (4qA or 4qA-L)
  • Permissive haplotype stabilizes DUX4 mRNA via polyadenylation signal (PAS) in pLAM region distal to the array
Key principle: Only contractions on 4qA or 4qA-L cause FSHD1. Contractions on 4qB are clinically silent.
Lemmers et al. (2012). Nature Genetics, 44(12), 1370–1374.

HP Tag Reliability

  • HP tags are reliable in unique flanking regions adjacent to D4Z4
  • Within D4Z4 array: very few heterozygous SNPs → phasing may fail
  • Most D4Z4 reads inherit HP tags from flanking-region phasing; some internal reads may lack HP tags

Chr4 vs Chr10 Discrimination

  • D4Z4 arrays share ~98.5–99% identity between chr4 and chr10
  • Discrimination relies on unique flanking sequences and a chr10-specific BlnI restriction site within D4Z4 units
  • Reads must extend into flanking regions for reliable chromosome assignment
  • Haplotype detection (4qA vs 10qA) requires reads extending past the last D4Z4 unit to detect pLAM

Flye Assembly Caveats

  • Minimum ~10× coverage; 30–40× recommended — per-allele coverage at D4Z4 typically 4–12× (marginal)
  • Flye may collapse identical D4Z4 copies, underestimating RU count
  • Resolution: take whichever has MORE RUs — assembly or longest raw read
Kolmogorov et al. (2019). Nature Biotechnology, 37(5), 540–546.

3. Algorithm Overview

The pipeline processes chr4 and chr10 independently. After BLAST annotation, every read has:

RU_Count, Has_Head (p13E-11), Has_Tail (pLAM), Haplotype (4qA/10qA/−), HP tag (1/2/none)

Phase 1: SEPARATE ALLELES → Phase 2: ASSIGN UNPHASED → Phase 3: COUNT per allele
PhaseQuestionMethod
1Which reads belong together?HP → RU-anchor → Jenks → single
2Which allele has spanning reads?RU-constraint → alignment → RU-proximity
3Read-level or assembly?Complete reads → Racon; else → Flye/raw-read

Press ↓ for full pseudocode of each phase

Phase 1: Separate Alleles

IF any reads on this chromosome have HP tags:
    Allele_1 = reads with HP == 1
    Allele_2 = reads with HP == 2
    unphased = reads without HP tag
    separation_method = 'hp'

ELSE (no HP tags at all):
    IF complete reads exist:
        complete_ru = median(RU_Count of complete reads)
        Allele_1 = reads with RU_Count <= complete_ru + 2
        Allele_2 = reads with RU_Count > complete_ru + 2
        separation_method = 'ru-anchor'
    ELSE:
        IF std(RU_counts) >= 1.5 AND len(reads) >= 2:
            Jenks 2-class split -> Allele_1 (shorter), Allele_2 (longer)
            separation_method = 'jenks'
        ELSE:
            Allele_1 = all reads
            Allele_2 = empty
            separation_method = 'single'
HP is always preferred — it uses flanking-region SNPs and doesn’t depend on RU count differences.

Phase 2: Assign Unphased Reads

Complete reads (Has_Head AND Has_Tail) span the full array and can only come from the shorter allele (healthy alleles ≥11 RU exceed ONT N50).

IF no complete reads:
    Skip to Phase 3 (all alleles use assembly)

IF complete reads already have HP tags:
    Already in the correct allele from Phase 1

IF complete reads lack HP tags (separation was by HP):
    Assign to the allele whose median RU is closest

All remaining unphased reads:
    IF allele has complete reads (max_RU = X) AND read RU > X + 2:
        Force-assign to the OTHER allele (ru-constraint)
    ELSE:
        minimap2 align read against HAP1 pool and HAP2 pool
        Assign to allele with more matching bases (alignment)
        Tie: assign to allele with closer median RU (ru-proximity)
Huang et al. (2024). J Transl Med, 22, Article 451.

Phase 3: Per-Allele Strategy

For each allele:

    IF allele has complete reads -> STRATEGY: READ-LEVEL
        spanning = complete + partial-distal reads
        raw_ref = longest spanning read

        IF >= 3 spanning reads:
            Racon consensus (raw_ref as seed, polish with others)
        ELSE:
            consensus = raw_ref as-is

        reference = consensus
        RU_count = BLAST d4z4.fa against consensus (hits > 1500 bp)

    ELSE -> STRATEGY: ASSEMBLY
        Run Flye on allele reads (--nano-hq --genome-size 300k)
        max_raw_ru = max(RU_Count) among reads in this allele

        IF Flye succeeded AND Flye_RU >= max_raw_ru:
            reference = Flye contig
        ELSE:
            reference = longest raw read

        RU_count = BLAST d4z4.fa against reference (hits > 1500 bp)

Press ↓ for details of each step

Step 1: EXTRACT_FSHD_READS

Extract reads from FSHD-associated regions in hg38 coordinates + unmapped reads.

BED (hg38):
    chr4:189000000-190500000     # 4q35 D4Z4 flanking
    chr10:133000000-134000000    # 10q26 D4Z4 flanking

samtools view -b -h -M -L regions.bed -> target.bam
samtools view -b -f 4 -> unmapped.bam
samtools merge -> subset.bam
Unmapped reads are critical: hg38 has an ~82 kb assembly gap at 4q35 causing many D4Z4 reads to be unmapped.

Step 2: ALIGN_T2T

Realign to T2T-CHM13v2.0, preserving MM, ML, HP, PS tags.

samtools fastq -T MM,ML,HP,PS subset.bam \
  | minimap2 -ax lr:hq -y --eqx --secondary=no -t $CPUS ref_t2t - \
  | samtools sort -o sample.t2t.bam
samtools index sample.t2t.bam
FlagPurpose
-T MM,ML,HP,PSCarry methylation + phasing tags through FASTQ
-yPropagate tags from FASTQ comment to SAM
--eqx=/X CIGAR operators for exact match/mismatch
--secondary=noSuppress secondary alignments

Step 3: EXTRACT_D4Z4

BED (T2T):
    chr4:193230000-193610000     # chr4 D4Z4
    chr10:134560000-134800000    # chr10 D4Z4

samtools view -b -h -M -L d4z4_regions.bed -> target.bam
samtools view -b -f 4 -> unmapped.bam
samtools merge -> d4z4.bam
samtools index d4z4.bam
Published output: {SAMPLE_ID}.d4z4.bam + .bai — for IGV review

Step 4: BLAST_ANNOTATE

samtools fasta d4z4.bam > reads.fasta
makeblastdb -in reads.fasta -dbtype nucl -out blastdb
blastn -db blastdb -query d4z4.fa       -> d4z4.blast    # RU counting (>1500 bp)
blastn -db blastdb -query pLAM-polyA.fa -> polya.blast   # distal anchor + haplotype
blastn -db blastdb -query P13E11.fasta  -> p13e11.blast  # proximal anchor

Three-Tier Chromosome Assignment

  1. BAM alignment (initial): minimap2 alignment to T2T reference
  2. BlnI motif counting (correction): chr4-type CTAGGTCTAGG vs chr10-type CTAGGCCTAGG — majority wins
  3. Haplotype override (final): 4qA (ATTAAA) → force chr4; 10qA (ATCAAA) → force chr10
Lowenstern et al. (2026). DUCKS4. Hum Genomics, 20, Article 21. • Huang et al. (2024). J Transl Med, 22, Article 451.

Step 4: Per-Read Annotation Fields

FieldLogic
RU_CountNumber of D4Z4 BLAST hits with alignment length > 1500 bp
ChromosomeThree-tier: BAM → BlnI motif → haplotype override
Has_Headp13E-11 BLAST hit found
Has_TailpLAM BLAST hit found
Completenesscomplete / partial-distal / partial-proximal / incomplete
Haplotype4qA (hapA mismatch < hapB) / 10qA (hapB < hapA) / − (no pLAM = 4qB or internal)
Read_LengthFrom BAM query_length

pLAM Haplotype Logic

  • hapA = 4qA PAS (ATTAAA) — functional, permissive, chr4-specific
  • hapB = 10qA PAS (ATCAAA) — non-functional, chr10
  • 4qB lacks pLAM entirely → no BLAST hit to either → Haplotype = ‘−’

Steps 5–7: Allele Assignment & Counting

Step 5: ALLELE_ASSIGN

Three-phase algorithm (see Algorithm section for pseudocode):

  • Phase 1: Separate alleles (HP → RU-anchor → Jenks → single)
  • Phase 2: Assign unphased reads (RU-constraint → minimap2 alignment → RU-proximity)
  • Phase 3: Determine read-level vs assembly strategy per allele

Step 6: READLEVEL_COUNT alleles with complete reads

spanning = complete + partial-distal reads → longest as raw_ref → Racon consensus (if ≥3) → BLAST d4z4.fa (hits >1500 bp)

Step 7: ASSEMBLY_COUNT alleles without complete reads

Flye --nano-hq --genome-size 300k --min-overlap 5000 → if Flye_RU ≥ max_raw_ru use Flye contig, else longest raw read → BLAST count

Vaser et al. (2017). Genome Res, 27(5), 737–746. • Xiao et al. (2025). D4Z4End2End. medRxiv.

Steps 8–9: Methylation & Report

Step 8: METHYLATION

modkit pileup t2t.bam meth_out/ \
  --ref ref_t2t --cpg --combine-strands --combine-mods \
  --modified-bases 5mC --phased \
  --include-bed meth_targets.bed --threads $CPUS

Targets: chr4:193540172-193543634, chr10:134738000-134741148

Outputs: HP1.bed, HP2.bed, ungrouped.bed

Runs independently — only needs T2T BAM from Step 2.

Step 9: REPORT

Combines allele assignments, RU counts (read-level + assembly), and methylation beds into two published tables:

  • {SAMPLE_ID}.repeats.tsv
  • {SAMPLE_ID}.methylation.tsv

10. Known Limitations

  1. Read length constraint. At N50 ~25–30 kb, complete reads limited to alleles ≤~10 RU. Ultra-long prep extends range but is not standard.
  2. Subtelomeric coverage. Effective per-allele coverage 30–50% lower than genome-wide. At 30× WGS, expect ~4–6 reads per allele.
  3. Flye tandem repeat collapse. Flye may underestimate RU count. Mitigated by comparing Flye RU with max single-read RU.
  4. Methylation coverage. At 30× WGS, per-allele methylation may be only 3–5 reads. ≥60× recommended for clinical-grade calls.
  5. CHM13 reference gap for 4qA. T2T-CHM13v2.0 carries 4qB on chr4. 4qA-specific pLAM/PAS absent from reference. BLAST detects pLAM in read sequence directly.
  6. Somatic mosaicism. Mosaic samples may show multiple RU count clusters from the same allele. Pipeline does not explicitly detect mosaicism.
  7. Cis duplications. Two adjacent D4Z4 arrays on one allele (~1.5% of Europeans) may produce two distinct RU groups in one HP.
